# Portfolio Optimization Platform

A Python-based web application for portfolio optimization and financial analytics using Modern Portfolio Theory.

## Features

- Markowitz Portfolio Optimization
- Minimum Variance Portfolio
- Sharpe Ratio Maximization
- Portfolio Analytics
- Investment Tracking

## Tech Stack

- Python
- Flask
- Pandas
- NumPy
- Bootstrap

## Future Improvements

- Live market data with yfinance
- Interactive dashboards
- Portfolio backtesting
- Streamlit migration
